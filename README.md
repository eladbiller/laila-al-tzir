# לילה על הציר

משחק מסיבות מוזיקלי בעברית, בהשראת משחקי ציר זמן מוזיקליים. הוא מיועד למסך משותף (טלוויזיה, מקרן או מחשב) ולטלפונים של השחקנים כשלטים.

## משחקים

1. פותחים את האתר על המסך המשותף ובוחרים **"פתחו מסך משותף"**.
2. השחקנים סורקים את קוד ה-QR, בוחרים שם ומצטרפים מהטלפון.
3. המארח מתחיל. בכל סבב השחקן שבתורו פותח את השיר, ואז ממקם אותו בין השנים בציר שלו.
4. מיקום נכון נותן נקודה ומוסיף את השיר לציר. אחרי הסבבים, בעל/ת מספר הנקודות הגבוה ביותר מנצח/ת.

יש גם מצב **"משחקים על מכשיר אחד"** למסיבה ללא טלפונים.

## חיבור בין מכשירים

החדרים משתמשים בחיבור WebRTC ישיר בין הדפדפנים, באמצעות PeerJS. אין צורך בחשבון או במסד נתונים, ואין מידע שנשמר לאחר שסוגרים את החדר. כדי שהטלפונים יישארו מחוברים, יש להשאיר את מסך המארח פתוח לאורך כל המשחק.

> החיבור מסתמך על גישה לאינטרנט כדי ליצור את ההיכרות הראשונית בין הדפדפנים. ברשתות ארגוניות נוקשות אפשר להשתמש במצב המכשיר היחיד.

## פרסום ב-GitHub Pages

1. צרו מאגר חדש ב-GitHub והעלו אליו את כל הקבצים בתיקייה הזו (`index.html`, `styles.css`, `app.js`, `README.md`).
2. במאגר: **Settings → Pages**.
3. תחת **Build and deployment**, בחרו **Deploy from a branch**.
4. בחרו את הענף `main`, את התיקייה `/(root)`, ולחצו **Save**.
5. GitHub יציג את כתובת האתר, בדרך כלל `https://<username>.github.io/<repository-name>/`.

האתר סטטי לחלוטין; אין צורך בבנייה, בחבילת npm או במפתחות API.
