# PICTIONARY — מסך משותף

משחק Pictionary בעברית, בנוי למסך משותף ולטלפונים של המשתתפים.

## איך משחקים

1. פותחים **מסך משותף** בטלוויזיה, במקרן או במחשב הראשי.
2. המשתתפים סורקים את ה־QR או מזינים את קוד החדר מהטלפון.
3. המארח מתחיל סבב. רק הצייר הפעיל מקבל את המילה הסודית ואת לוח הציור בטלפון שלו.
4. הציור מוזרם למסך הגדול בזמן אמת, והקבוצה מנחשת במשך 60 שניות.

המסך הגדול מנהל את הניקוד, הטיימר והתורות. אפשר גם לשחק על מכשיר יחיד במצב מקומי.

## טכנולוגיה

הפרויקט סטטי ומתאים ישירות ל־GitHub Pages. הוא משתמש ב־PeerJS לחיבור ישיר בין הדפדפנים וב־QRCode.js להצגת קוד הצטרפות. נדרש חיבור אינטרנט בזמן פתיחת החדר והצטרפות השחקנים.
